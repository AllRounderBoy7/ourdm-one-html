### 2. Mobile App (Android)
```bash
# Install Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init OurDM com.ourdm.app
npm run build
npx cap add android
npx cap sync
npx cap open android
# Build APK in Android Studio
```

### 3. Mobile App (iOS)
